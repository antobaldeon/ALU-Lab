¿Cómo funciona el método de Jacobi?

Despeja cada variable usando la diagonal de A. En cada iteración, todas las variables se calculan con los valores de la iteración anterior, sin reutilizar valores recién calculados.

xᵢ⁽ᵏ⁺¹⁾ = (bᵢ − ∑ⱼ≠ᵢ aᵢⱼ xⱼ⁽ᵏ⁾) / aᵢᵢ

  1. Analiza la matriz. Es estrictamente diagonal dominante por filas si |aᵢᵢ| > ∑ⱼ≠ᵢ |aᵢⱼ| en todas las filas. Esta condición garantiza la convergencia de Jacobi para cualquier vector inicial.
  2. Elige un punto de partida. La guía utiliza x⁽⁰⁾ = (0, 0, 0, 0)ᵀ. Aquí puedes modificarlo.
  3. Repite y compara. Usamos el error relativo global e = ‖x⁽ᵏ⁾ − x⁽ᵏ⁻¹⁾‖∞ / ‖x⁽ᵏ⁾‖∞. La norma infinito es el mayor valor absoluto de las componentes. Se detiene cuando e ≤ ε; ε = 0.0001 equivale a 0.01 %.
La dominancia estricta es suficiente, pero no necesaria: si no se cumple, este análisis no garantiza convergencia. Se requiere diagonal no nula. Si el vector nuevo es cero, el error es 0 cuando no hubo cambio e infinito en caso contrario. El residuo ‖Ax − b‖∞ permite comprobar la aproximación.

El método de Doolittle

Divide un problema en dos sistemas triangulares más sencillos.

A = L · U

¿Cómo funciona?

  1. Factorización. Construye L triangular inferior con unos en su diagonal y U triangular superior.
  2. Sustitución hacia adelante. Resuelve Ly = b para encontrar el vector intermedio y.
  3. Sustitución hacia atrás. Resuelve Ux = y para obtener la solución x.
Esta implementación no utiliza pivoteo. Si aparece un pivote cero o de magnitud menor que 10⁻¹², el cálculo se detiene; esto no implica necesariamente que el sistema no tenga solución.
